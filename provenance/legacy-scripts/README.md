# Legacy scripts

These scripts are retained for provenance only. They generated earlier v1/v2 figure families during development and are not part of the active v1.0 reproducibility route.

For the active release route, use:

```bash
python scripts/03_run_diagnostics.py
python scripts/01_make_tables.py
python scripts/05_generate_matplotlib_figures_v3.py
python scripts/06_run_sensitivity_checks.py
```
